# Sentinel CI/CD Supply Chain Security Guard

Use this skill when auditing GitHub Actions workflows (`.github/workflows/*.yml`), CI/CD configuration files, ChatOps bots, or release automation pipelines.

## Audit Capabilities & Detection Rules

### 1. `pull_request_target` with PR Head Checkout (CWE-829 / CWE-94)
- **High-Risk Pattern**:
  ```yaml
  on: pull_request_target
  steps:
    - uses: actions/checkout@v4
      with:
        ref: ${{ github.event.pull_request.head.sha }}
  ```
- **Risk**: Code from an untrusted fork runs inside a runner that has access to base repository secrets and `GITHUB_TOKEN`.
- **Validation**: Check if downstream steps execute `npm test`, `npm install`, `make`, `python setup.py`, or arbitrary build scripts.

### 2. TOCTOU & Authorization Persistence Across `synchronize` (CWE-367)
- **High-Risk Pattern**:
  ```yaml
  on:
    pull_request_target:
      types: [labeled, synchronize]
  if: contains(github.event.pull_request.labels.*.name, 'ok to test')
  ```
- **Risk**: When a maintainer labels a PR (`labeled`), the authorization condition is satisfied. If the label is never removed by the workflow or automation, any subsequent commit pushed to the PR triggers `synchronize`, automatically executing the unreviewed new commit with privileged secrets.
- **Verification**:
  - Search if the repository contains an automated label removal step (e.g. `actions/github-script` removing the label).
  - Verify whether execution is strictly restricted to `github.event.action == 'labeled'`.

### 3. Untrusted Artifact Extraction Across `workflow_run` (CWE-502 / CWE-22)
- **High-Risk Pattern**:
  ```yaml
  on:
    workflow_run:
      workflows: ["Untrusted PR Workflow"]
      types: [completed]
  steps:
    - uses: actions/download-artifact@v4
    - run: tar -xf artifact.tar  # Path traversal / tar-slip risk
  ```
- **Risk**: The consumer job runs in the base repository context with secrets, but consumes an artifact generated by untrusted fork code.

### 4. Expression Script Injection in Runner Shells (CWE-78 / CWE-94)
- **High-Risk Pattern**:
  ```yaml
  run: |
    echo "${{ github.event.pull_request.title }}"
    branch="${{ github.head_ref }}"
  ```
- **Remediation**: Always pass GitHub expressions via intermediate environment variables (`env: TITLE: ${{ ... }}`), never interpolated directly inside `run:` strings.

## Triaging and Verification Protocol

1. **Verify Triggers & Trust Boundaries**: Identify the trigger event (`pull_request`, `pull_request_target`, `workflow_run`, `issue_comment`).
2. **Trace Code Origin**: Track whether `actions/checkout` checks out base branch (`main`), merge commit (`github.sha`), or fork head (`github.event.pull_request.head.sha`).
3. **Map Sinks & Secrets**: Identify whether credentials (`secrets.*`) or write tokens (`contents: write`, `id-token: write`) are exposed to steps running untrusted commands.
4. **Formulate Defensive Patches**: Propose decoupled 2-stage architectures or strict event gates.
